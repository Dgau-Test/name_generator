# name-generator

Гибкая Python-библиотека для процедурной генерации имён и других наименований на основе настраиваемых профилей.

Генератор позволяет описывать структуру наименований через шаблоны, задавать допустимые символы и слоги, управлять вероятностью выбора отдельных частей, ограничивать последовательности гласных и согласных, задавать автоматические замены и запрещённые комбинации.

Библиотека не привязана к конкретным культурам или наборам имён: правила генерации определяются пользователем через `NameProfile`.

## Возможности

* генерация наименований по настраиваемым шаблонам;
* взвешенный случайный выбор частей наименования;
* поддержка собственных алфавитов;
* встроенные русский и английский алфавиты;
* ограничения минимальной и максимальной длины;
* ограничение количества гласных и согласных подряд;
* группы согласных для начала и конца слога;
* готовые начальные, средние и конечные части;
* запрещённые комбинации символов;
* автоматические замены после генерации;
* случайная вставка апострофа;
* генерация уникальных значений с раздельным контролем уникальности.

## Быстрый старт

Для генерации необходимо создать профиль и передать его в `NameGenerator`.

```python
from name_generator import NameGenerator
from name_generator.models import RussianNameProfile, WeightedValue


profile = RussianNameProfile(
    consonants=[
        WeightedValue('л'),
        WeightedValue('р'),
        WeightedValue('н'),
    ],
    vowels=[
        WeightedValue('а'),
        WeightedValue('э'),
        WeightedValue('и'),
    ],
    start_syllables=[
        WeightedValue('Эл', 3),
        WeightedValue('Аэ', 1),
    ],
    end_syllables=[
        WeightedValue('рион'),
        WeightedValue('эль'),
    ],
    patterns=[
        WeightedValue('SE'),
    ],
)

generator = NameGenerator()

print(generator.generate(profile))
```

Возможный результат:

```text
Элрион
```

Результат является случайным и зависит от заданных значений и их весов.

## WeightedValue

`WeightedValue` связывает значение с его относительным весом:

```python
WeightedValue('Эл', 10)
WeightedValue('Аэ', 3)
WeightedValue('Ил', 1)
```

Чем больше вес, тем выше вероятность выбора значения.

По умолчанию вес равен `1.0`:

```python
WeightedValue('Эл')
```

Вес должен быть > 0.

## Профиль генерации

Основные правила описываются через `NameProfile`.

Для русского и английского алфавитов доступны готовые классы:

```python
from name_generator.models import EnglishNameProfile, RussianNameProfile
```

Основные параметры профиля:

| Параметр                 | Назначение                                      |
| ------------------------ | ----------------------------------------------- |
| `alphabet`               | Алфавит профиля                                 |
| `consonants`             | Одиночные согласные                             |
| `vowels`                 | Гласные и допустимые последовательности гласных |
| `onset_clusters`         | Группы согласных для начала слога               |
| `coda_clusters`          | Группы согласных для конца слога                |
| `start_syllables`        | Готовые начальные части                         |
| `middle_syllables`       | Готовые внутренние части                        |
| `end_syllables`          | Готовые окончания                               |
| `patterns`               | Шаблоны построения                              |
| `min_length`             | Минимальная длина                               |
| `max_length`             | Максимальная длина                              |
| `max_consonants_in_row`  | Максимальное количество согласных подряд        |
| `max_vowels_in_row`      | Максимальное количество гласных подряд          |
| `forbidden_combinations` | Запрещённые последовательности                  |
| `replacement_rules`      | Правила автоматической замены                   |
| `apostrophe_chance`      | Вероятность добавления апострофа                |

## Шаблоны

Шаблон определяет, из каких частей будет построено наименование.

Поддерживаются следующие символы:

| Символ | Источник           |
| ------ | ------------------ |
| `C`    | `consonants`       |
| `V`    | `vowels`           |
| `K`    | `onset_clusters`   |
| `D`    | `coda_clusters`    |
| `S`    | `start_syllables`  |
| `M`    | `middle_syllables` |
| `E`    | `end_syllables`    |

Например:

```python
patterns=[
    WeightedValue('SE', 5),
    WeightedValue('SME', 3),
    WeightedValue('KVE', 1),
]
```

Шаблон:

```text
SME
```

означает:

```text
start_syllable + middle_syllable + end_syllable
```

Каждый шаблон также является `WeightedValue`, поэтому частоту разных структур можно регулировать весами.

Если шаблон использует часть профиля, для которой не задано ни одного значения, профиль считается некорректным.

## Ограничения

Можно контролировать длину результата:

```python
profile = RussianNameProfile(
    min_length=4,
    max_length=12,
)
```

А также максимальное количество согласных и гласных подряд:

```python
profile = RussianNameProfile(
    max_consonants_in_row=2,
    max_vowels_in_row=2,
)
```

Если сгенерированный вариант не удовлетворяет ограничениям, генератор повторяет попытку генерации.

## Запрещённые комбинации

Через `forbidden_combinations` можно исключить нежелательные последовательности:

```python
profile = RussianNameProfile(
    forbidden_combinations=[
        'гз',
        'ааа',
        'иии',
    ],
)
```

Проверка выполняется без учёта регистра.

## Автоматические замены

`replacement_rules` позволяют нормализовать результат до финальной проверки:

```python
profile = RussianNameProfile(
    replacement_rules={
        'аа': 'а',
        'ии': 'и',
        'ллл': 'лл',
    },
)
```

Например:

```text
Ааэлион
```

может быть преобразовано в:

```text
Аэлион
```

до проверки итогового наименования.

## Апостроф

Можно задать вероятность случайного добавления апострофа:

```python
profile = RussianNameProfile(
    apostrophe_chance=0.05,
)
```

Значение задаётся в диапазоне от `0.0` до `1.0`.

```python
apostrophe_chance=0.05
```

соответствует вероятности `5%`.

## Уникальные значения

`NameGenerator` может не возвращать уже сгенерированные значения:

```python
name = generator.generate(
    profile,
    unique=True,
)
```

Для разных типов наименований можно использовать независимые области уникальности:

```python
name = generator.generate(
    profile,
    unique=True,
    exist_key='names',
)

city = generator.generate(
    profile,
    unique=True,
    exist_key='cities',
)
```

Одинаковое значение может существовать в разных областях, но не может быть повторно возвращено внутри одной области.

История уникальных значений хранится в экземпляре `NameGenerator`.

## Собственный алфавит

Для другого языка или вымышленной письменности можно создать собственный `Alphabet`:

```python
from name_generator.models import Alphabet, NameProfile


alphabet = Alphabet(
    vowels=frozenset('aeiou'),
    consonants=frozenset('bcdfghjklmnpqrstvwxyz'),
)

profile = NameProfile(
    alphabet=alphabet,
)
```

`modifiers` предназначен для буквенных символов, которые не относятся непосредственно ни к гласным, ни к согласным:

```python
alphabet = Alphabet(
    vowels=frozenset(...),
    consonants=frozenset(...),
    modifiers=frozenset(...),
)
```

## Пример культур

Каталог [`examples`](examples) содержит пример построения более высокого уровня поверх `name-generator`.

В примере представлены культуры эльфов, орков и людей,
для которых настроена генерация имён, фамилий,
городов и стран.

Пример демонстрирует, как несколько `NameProfile` можно объединить в модель культуры и создать специализированный генератор:

```python
from cultures import ELF, CultureNameGenerator


generator = CultureNameGenerator(ELF)

print('Имя:', generator.get_name())
print('Фамилия:', generator.get_surname())
print('Город:', generator.get_city_name())
print('Страна:', generator.get_country_name())
```

Культуры из `examples` не являются частью основного пакета `name_generator` и предназначены для демонстрации способов расширения библиотеки.
